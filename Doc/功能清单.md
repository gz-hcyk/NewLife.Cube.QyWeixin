# NewLife.Cube.QyWeixin 功能清单

> 版本：v1.1 | 日期：2026-10-05

> 状态标记：✅ 已完成 | 🟡 部分完成 | ❌ 未开始 | — 不适用

本库是纯类库，没有管理页面。拆分只发生在「可单测的报文/算法」和「要打企微的薄客户端」之间，不拆前后端。

## 拆分

| 需求项 | 原因 | 拆分结果 |
|--------|------|----------|
| P0-2 应用消息 | 报文可离线断言，发送依赖网络 | P0-2a 消息体 + P0-2b 发送/撤回客户端 |
| P0-4 回调 | 解析与分发可离线断言，HTTP 端点依赖宿主 | P0-4a 解析分发 + P0-4b 回调端点 |
| P1-3 网页授权 | URL 可离线断言，code 交换依赖网络 | P1-3a 授权 URL + P1-3b code 交换 |
| P1-4 JS-SDK | 签名可离线断言，取票依赖网络 | P1-4a 签名 + P1-4b 取票 |
