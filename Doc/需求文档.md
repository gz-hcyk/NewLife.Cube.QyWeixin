# NewLife.Cube.QyWeixin 需求文档

> 版本：v1.1 | 日期：2026-10-05

本文档描述企业微信自建应用类库要覆盖的能力。完成状态见[功能清单](功能清单.md)，实现方式见[架构设计](架构设计.md)。

## 1. 背景与愿景

### 1.1 系统定位

给 NewLife.Cube 项目提供可安装的企业微信自建应用服务端能力。业务系统引用包即可发消息、收回调、管应用和通讯录，不改 Cube / Cube.Core / XCode 源码，也不带业务实体。

### 1.2 愿景

自建应用常用服务端接口在一个客户端里按官方文档能对上号。客户联系及相邻的外部客户产品线明确排除，避免包的职责膨胀。

## 2. 核心目标

| 编号 | 目标 | 所属层级 | 一句话描述 |
|------|------|----------|------------|
| P0 | 消息与回调 | 核心 | 素材、全部常用应用消息、撤回、被动回复、回调分发 |
| P1 | 应用与身份 | 核心 | 应用/菜单、账号转换、网页授权辅助、JS-SDK 签名 |
| P2 | 通讯录写 | 核心 | 部门/成员/标签写入与异步任务，并和只读同步作业分开 |
| P3 | 协作薄封装 | 配套 | 应用群聊、工作台、日程/打卡/审批的读和最小写 |

## 3. 功能需求

### 3.1 P0 — 消息与回调

- **P0-1 素材**：上传临时素材、获取临时素材、上传图片得到 URL。
- **P0-2 应用消息**：在已有 text / textcard / template_card / update_taskcard 上补 image、voice、video、file、news、mpnews、markdown、miniprogram_notice，以及 message/recall、模板卡片更新。
- **P0-3 被动回复**：按文档生成明文并加密成回包 XML。
- **P0-4 回调分发**：保持 `IQyWeixinEventHandler`；增加结构化报文、事件常量目录，以及可返回回复的扩展入口。

### 3.2 P1 — 应用与身份

- **P1-1 应用与菜单**：获取/设置应用，自定义菜单创建、读取、删除。
- **P1-2 账号转换**：userid 与 openid 互转。
- **P1-3 网页授权**：生成与魔方 OAuth 一致的授权地址，并用 code 换 userid；不复制一套登录落库。
- **P1-4 JS-SDK**：企业 ticket、应用 ticket、wx.config / agentConfig 签名。ticket 不下发到浏览器。

### 3.3 P2 — 通讯录写

- **P2-1 部门成员标签**：创建、更新、删除，以及邀请。
- **P2-2 异步任务**：批量导入返回 jobid 后可查询结果。
- **P2-3 同步策略**：定时作业只从企微拉到魔方。默认仍按企微覆盖本地映射字段；可改为只插入本地不存在的记录。作业不调用写接口。

### 3.4 P3 — 协作薄封装

- **P3-1 应用群聊**：创建、修改、读取、发消息。
- **P3-2 工作台**：keydata 模板和用户数据，并保留原始请求体入口。
- **P3-3 日程打卡审批**：创建/更新/查询/取消日程的薄封装；打卡记录、日报、月报；审批单查询与模板详情。不展开审批控件和会议全量。

## 4. 不做什么

- 客户联系 / externalcontact / 获客助手 / 微信客服。
- 家校、政民、会议全量、微盘全量、企业支付、会话存档。
- 修改 NewLife.Cube、NewLife.Cube.Core、XCode 的源码或包内容。
- 在定时同步作业里把魔方部门/用户推回企微。
